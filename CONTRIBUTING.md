# Contributing

Thank you for your interest in contributing to **Awesome Websites and Portfolios**!

This repository aims to help developers discover inspiring open-source websites, portfolios, and web projects with publicly available source code and live demos.

## How to Contribute

1. Find an interesting website, portfolio, or web project.
2. Verify that its source repository is public.
3. Visit the live demo and check that it works, when a demo is available.
4. Identify the appropriate category.
5. Add the project using the listing format below.
6. Submit a pull request with a brief explanation of your addition.

## Project Listing Format

Use this format when adding a project:

```markdown
### Project Name

- **Live Demo:** [Visit Website](https://example.com)
- **Source:** [GitHub Repository](https://github.com/owner/repository)
- **Description:** A short, accurate description of the project.
- **Tech Stack:** Technologies verified from the source code.
```

Replace the example name and URLs with real project details.

## Contribution Guidelines

- Add only projects with publicly accessible source code.
- Verify links before submitting a contribution.
- Keep descriptions concise, useful, and accurate.
- Do not invent technologies, features, statistics, or project details.
- Avoid duplicate entries.
- Respect each project's license and attribution requirements.
- Keep entries alphabetically ordered within each category where practical.
- Do not submit spam, malicious projects, or misleading links.

## Choosing a Category

- **Developer Portfolios:** Personal websites showcasing developers and their work.
- **Creative Portfolios:** Websites for designers, photographers, musicians, artists, and other creatives.
- **SaaS and Startups:** Product websites and startup landing pages.
- **Web Applications:** Interactive tools, dashboards, and full-stack applications.
- **Open-Source Templates:** Reusable website templates and starter kits.

If a project fits multiple categories, choose the most relevant one.

## Before Submitting

Please check that:

- The project is not already listed.
- Its source repository is public.
- The live demo works, if one is provided.
- The description and technologies are accurate.
- The formatting matches the existing entries.

Thank you for helping make this collection useful for everyone!
