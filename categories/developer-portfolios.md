# Developer Portfolios

A collection of open-source developer portfolios with live websites and publicly available source code. Explore layouts, project showcases, typography, navigation, and implementation choices.

### React Portfolio Template

A customizable developer portfolio template for showcasing projects, career history, and skills. It supports responsive layouts, dark and light modes, and a multi-component design.

- **Live Demo:** [View Website](https://yujisatojr.github.io/react-portfolio-template/)
- **Source:** [GitHub Repository](https://github.com/yujisatojr/react-portfolio-template)
- **Tech Stack:** React, TypeScript, JavaScript, HTML, SCSS, Node.js
- **License:** [MIT License](https://github.com/yujisatojr/react-portfolio-template/blob/master/LICENSE)

### Brittany Chiang — v4 Portfolio

The fourth iteration of Brittany Chiang's personal developer portfolio, featuring a polished dark-themed design, project showcases, and an experience-focused layout. Built with Gatsby.

- **Live Demo:** [Visit Website](https://v4.brittanychiang.com/)
- **Source:** [GitHub Repository](https://github.com/bchiang7/v4)
- **Tech Stack:** Gatsby, React, JavaScript, CSS
- **License:** [MIT License](https://github.com/bchiang7/v4/blob/main/LICENSE)
- **Attribution:** Please credit the original creator when reusing the work, as requested in the repository README.

### How to add a project

- **Name:** Project or portfolio name
- **Live Demo:** URL of the working website
- **Source:** URL of the public GitHub repository
- **Description:** A short, accurate description
- **Tech Stack:** Technologies used, when verified
