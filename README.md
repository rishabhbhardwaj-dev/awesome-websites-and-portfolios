## What belongs here?

- **Open source:** Publicly accessible source code.
- **Live demo:** A working public website or demo, where applicable.
- **Useful to explore:** A clear purpose, thoughtful implementation, or strong design.
- **Accurate details:** Verified source links, live links, and concise descriptions.
- **Respect for licensing:** Check each project's license before reusing its code or assets.

## Listing format

Use this format when adding a project:

```markdown
### [Project Name](LIVE_DEMO_URL)

- **Source:** [Owner/Repository](SOURCE_REPOSITORY_URL)
- **Category:** Developer Portfolio
- **Description:** A concise description of the project.
- **Tech stack:** React, TypeScript, CSS
```

Replace the example values with verified project details.
